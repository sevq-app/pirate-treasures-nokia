# Сокровища Марата — прототип
Java ME MIDP 2.0 / CLDC 1.1, Nokia C1-02 (128×160).
Первый прототип: 6×6, обмен соседних кристаллов, сбор троек, падение, цели, ограничение ходов, сохранение уровня и монет (RMS).
Управление: стрелки или 2/4/6/8, OK или 5 — выбор, 0 — новая доска.
Старт: 500 000 монет. План: 1000 уровней, 20 островов по 50.
Пока отсутствуют: препятствия, острова, бонусы, балансировка и проверка реальным телефоном. Текущий код не подтверждён сборкой.
